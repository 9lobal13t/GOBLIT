## Найденные проблемы

### 1. Ошибка DataStore в Studio не распознаётся как постоянная

`isPermanentStoreError` в `src/server/Services/PlayerDataService.luau` ищет в тексте ошибки `StudioAccessToApisNotAllowed` или `publish this place`. Ни того, ни другого в ошибке, которую получает `pcall`, нет.

Текст в Output (сообщение самого Roblox, уровень ERR):

```
DataStoreService: StudioAccessToApisNotAllowed: Cannot write to DataStore from studio if API access is not enabled. API: UpdateAsync, Data Store: GOBLIT_Profiles_v1
```

Текст, который получает `pcall` (видно в сообщении `ErrorReporter`, уровень WARN):

```
[GOBLIT][PlayerData.load] UserId 688321161, попытка 1: 403: Cannot write to DataStore from studio if API access is not enabled.
```

То есть сама ошибка: `403: Cannot write to DataStore from studio if API access is not enabled.`

Последствия: загрузка повторяется 4 раза с паузой ~3 с, и только потом сохранение отключается. От старта сервера до `SaveDisabled = true` проходит около 9.5 с. С двумя игроками каждый делает свои 4 попытки. Уведомление «Сохранение отключено: не удалось загрузить профиль. Прогресс этой сессии не сохранится.» тоже приходит с этой задержкой.

### 2. Персонаж иногда появляется до постройки Заставы

Запуск 1: персонаж появился в точке (−1.9; 4; 3.5), рядом с маяком, а не на `OutpostSpawn` (0; 1.5; 50). Площадка при этом существует и включена. После `LoadCharacter()` персонаж появился правильно: (2; 4.7; 47), лицом к площади. В запусках 2 и 3 появление было верным.

Вероятная причина: `Players.CharacterAutoLoads = true`, и персонаж загружается раньше, чем `HubService` строит Заставу. `HubService` запускается последним в `src/server/init.server.luau`. Причина подтверждена косвенно, по перезагрузке персонажа; порядок событий не измерялся.

## Заметки для `docs/PITFALLS.md` (не внесены)

- Ошибка DataStore в Studio без доступа к API приходит в `pcall` как `403: Cannot write to DataStore from studio if API access is not enabled.`. Код `StudioAccessToApisNotAllowed` есть только в отдельной строке Output.
- `capture_screenshot` возвращает интерфейс без 3D-сцены, когда окно Studio не в фокусе или свёрнуто.
- `rokit install` в неинтерактивной среде падает на неподтверждённых инструментах; нужен `rokit trust <автор/инструмент>`.
- Похоже, `simulate_keyboard_input` с `tap` и `duration` возвращает ответ раньше, чем клавиша отпущена: после ответа на `W` (3 с) персонаж продолжил идти. Не перепроверено.
