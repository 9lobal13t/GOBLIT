### Окончания строк

В системном конфиге Git для Windows стоит `core.autocrlf=true` (`C:/Program Files/Git/etc/gitconfig`). После появления `.gitattributes` команда `git checkout-index --force --all` файлы **не переписала**: `git ls-files --eol` показывал `i/lf w/crlf`. Файлы, которые Git считает неизменёнными, она пропускает. Помогло (рабочая копия была чистой): удалить отслеживаемые файлы и выполнить `git checkout -- .`.

Ещё две ловушки при диагностике:
- `git archive` на Windows тоже применяет `core.autocrlf`; нужен `git -c core.autocrlf=false archive`;
- `grep -c $'\r'` в Git Bash не находит `\r`, проверять нужно через `od -c`.

### StyLua: почему 14 файлов

С LF-окончаниями StyLua 2.6.0 на Windows требовал переносить строки в 14 файлах. Причин было две:
1. Ширина строки считалась в байтах: русская буква — 2 байта. Проверено на примере: `print("…")` с 79 русскими буквами (149 байт) не проходит, с 79 латинскими проходит. Пример из кода: `init.server.luau:41` — 92 символа, 137 байт.
2. `HeroService.luau:64` — латиница, 122 позиции при табуляции в 4. Настоящее превышение `column_width = 120`.

Облачная сессия подтвердила, что её StyLua был собран без поддержки Luau и ничего не проверял. Исправлено в `3d83b36`.

3. **R10 впритык:** `Vitals` начинается ровно там, где кончается `ThumbstickStart` (x 103), до кнопки прыжка 8 точек.
4. При «Мелком» на ПК весь интерфейс очень мелкий (текст описаний ~10 пикселей). R14 касается только телефонов, на ПК размеры не измерялись.

## Заметки об инструментах (для `docs/PITFALLS.md`, не внесены)

- Вывести окно Studio на передний план из терминала получается, если перед `SetForegroundWindow` сымитировать нажатие Alt (`keybd_event(0x12, …)`). Без этого Windows возвращает `False`, и снимки идут без 3D-сцены.
- Подмену начертания проверять по снимку (толщина и ширина строки), а не по `TextBounds` сразу после смены `FontFace`.

- Чтобы проверить телефон «до первого касания», эмуляцию нужно включить в режиме редактирования (`set_device_simulator` с `target = edit`) до запуска Play. Иначе клиент стартует как ПК.
- Для оценки шрифтов снимок 1:1 мелкий: помогает обрезка и увеличение ×2 без сглаживания (Pillow, `Image.NEAREST`).

- `SetForegroundWindow` из терминала возвращает `False`: Windows не даёт фоновому процессу забрать фокус. Тем не менее при открытом окне Studio снимки в этом прогоне были с 3D-сценой.
- `VirtualInput:SendMouseButton` отказывается кликать по интерфейсу Roblox: `position (138.0, 34.0) hits CoreGUI`. Окно чата открывается клавишей `Slash` через `simulate_keyboard_input`. Инструмент вернул `Unknown error`, но клавиша сработала.
- `ChatWindowConfiguration.AbsolutePosition/AbsoluteSize` у нового чата возвращают 0 — положение окна чата видно только на снимке.
- `ProximityPrompt` в режиме касаний срабатывает от долгого касания `VirtualInput` в экранной точке объекта (`Camera:WorldToViewportPoint`); у `BillboardGui` подсказки `AbsolutePosition` = 0,0.
- Исчезающее уведомление (`CanvasGroup`, 0.25 с) остаётся в раскладке: при подсчёте видимых нужно смотреть на `GroupTransparency`, а не на `TextTransparency`.
- `python -I` отключает `PYTHONUTF8`; для UTF-8 нужен флаг `-X utf8`.
