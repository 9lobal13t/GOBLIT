# Ловушки GOBLIT

Журнал проблем, на которые мы наступили в этом проекте, и способов их обойти. Каждая новая находка записывается сюда сразу, вместе с датой.

Уроки прошлого проекта — в [LESSONS_BRAINROT_BANDITS.md](LESSONS_BRAINROT_BANDITS.md).

## Luau и проверка типов

**Строки во вложенных таблицах «расширяются» до `string`** (2026-10-19).
Если записать `{ kind = "chest" }` внутри большой таблицы данных, тип-чекер видит `kind: string`, а не `"chest"`, и поле с типом-перечислением не проходит проверку.
Решение — маленькие типизированные конструкторы: `feature("chest", x, z)` в `Rooms.luau`, `add(...)` / `mul(...)` в `Perks.luau`.

**Тип массива берётся по первому элементу** (2026-10-19).
Массив `{ Ui.corner(), Ui.stroke(...) }` получает тип `{ UICorner }`, и следующий элемент «не подходит».
Решение: вспомогательные функции оформления возвращают `Instance`.

**`xpcall` от функции без результата** (2026-10-19).
По типам такой вызов возвращает только `ok`, без текста ошибки.
Решение: сохранять ошибку в обработчике через замыкание (см. `ErrorReporter.try`).

**Свойства в `Ui.new("Frame", { ... })` тип-чекер не проверяет** (2026-10-19).
Таблица свойств имеет тип `any`, поэтому опечатка в имени свойства всплыла бы только в Studio.
Решение — `tools/check_ui_props.py`: скрипт сверяет имена свойств с определениями Roblox API и входит в `tools/check.sh`.

## Порядок запуска и гонки

**Сигнал может сработать прямо внутри `start()`** (2026-10-19).
Если DataStore недоступен, профиль «загружается» мгновенно, и `ProfileLoaded` срабатывает внутри `PlayerDataService.start`. Подписавшийся позже его пропустит.
Правило: подписки делаются в `init()`, работа — в `start()`.

**Быстрый перезаход на тот же сервер** (2026-10-19).
Новая загрузка профиля могла прочитать данные до того, как допишется финальное сохранение прошлой сессии.
Решение: загрузка ждёт, пока завершится выгрузка того же `UserId`. Отдельная защита не даёт загрузить профиль одного игрока дважды.

## Данные

**Точки появления внутри препятствий** (2026-10-19).
Общие точки появления по умолчанию оказались внутри колонн шаблона «Круг колонн».
Ошибку поймал тест `tests/Definitions.spec.luau`, который проверяет каждую точку на пересечение с препятствиями. Новые шаблоны комнат проверяются им автоматически.

## Среда разработки (облачная сессия)

**Релизы GitHub недоступны** (2026-10-19).
Скачать готовые программы с GitHub нельзя. Rojo, StyLua, selene и Lune собраны через `cargo install` с crates.io. luau-lsp собран из исходников через `git clone`.
luau-lsp нужно собирать компилятором clang: GCC падает на ложном предупреждении из-за `-Werror`.

**selene не может скачать API Roblox** (2026-10-19).
Его HTTP-клиент игнорирует прокси и не доверяет его сертификату, поэтому шаг selene в `tools/check.sh` пропускается с пометкой.
Неиспользуемые переменные и подобное ловит luau-lsp: его линтер включён.

## Настройка компьютера (Windows)

**Установщик Claude Code не прописывает путь к программе** (2026-10-20).
После `irm https://claude.ai/install.ps1 | iex` команда `claude` «не распознана». Об этом предупреждает строка `Setup notes` в выводе установщика.
Путь добавляется один раз (команды — в [LOCAL_SETUP.md](LOCAL_SETUP.md)).

**Уже открытое окно PowerShell не видит новый путь** (2026-10-20).
Новый путь работает только в новых окнах. В текущем окне его можно обновить командой `$env:PATH = ...` (см. LOCAL_SETUP.md). Повторный запуск команды добавления пути только дублирует запись.

**PowerShell от администратора не нужен** (2026-10-20).
Строка `PS C:\WINDOWS\system32>` означает окно администратора. Для установки и работы нужно обычное окно: `PS C:\Users\<имя>>`.

## Найдено проверкой в Studio (2026-10-20)

Подробности и замеры — в [reports/phase1-studio-check.md](reports/phase1-studio-check.md).

**Текст ошибки DataStore в `pcall` не такой, как в Output.**
В Output: `DataStoreService: StudioAccessToApisNotAllowed: Cannot write to DataStore from studio if API access is not enabled. …`
В `pcall`: `403: Cannot write to DataStore from studio if API access is not enabled.` — кода `StudioAccessToApisNotAllowed` там нет.
Распознавание вынесено в `Logic/DataStoreErrors.luau` (код `403:` и текст `API access is not enabled`) и проверено тестами на настоящих сообщениях. Раньше сохранение отключалось только через ~10 с повторных попыток.

**Персонаж появляется раньше, чем построен мир.**
При `CharacterAutoLoads = true` персонаж мог появиться до того, как сервер построил Заставу и `SpawnLocation`, — у маяка вместо площадки.
Решение: `CharacterAutoLoads = false` (в `default.project.json` и в коде). `SpawnService` создаёт персонажа после постройки мира и пересоздаёт его после смерти. Уже появившегося до старта скриптов персонажа он тоже пересоздаёт.

**`Player:LoadCharacter` устарел.** Нужно использовать `LoadCharacterAsync` (так сказано в определениях API).

**Интерфейс, уменьшенный под маленький экран, нечитаем.**
Автомасштаб до 0,7 давал на iPhone 7 текст в 9 точек и кнопки в 22 точки.
Решение: при сенсорном вводе (`UserInputService.PreferredInput == Touch`) не уменьшать ниже макета, итоговый масштаб не ниже 0,8, все кнопки не ниже `Theme.TouchTarget` (44 точки). Длинный список в панели прокручивается.

**Кнопка теряет фон после смены выбора.**
Вероятная причина — встроенная подсветка `AutoButtonColor` спорит с цветом, который код меняет программно. У кнопок, цвет которых меняет код, `AutoButtonColor = false`. Невыбранные варианты получили заметный фон и рамку.

**Кириллица в шрифте Builder Sans не подтверждена.**
Интерфейс переведён на Montserrat через `Font.new("rbxasset://fonts/families/Montserrat.json", …)`. Montserrat с кириллицей проверен в прошлом проекте. В `Enum.Font` значения Montserrat нет.

**Скриншоты Studio без 3D-сцены.**
Когда окно Studio свёрнуто или не в фокусе, Studio не рисует 3D и на снимках виден только интерфейс. Перед проверкой внешнего вида окно Studio должно быть на переднем плане.

**`rokit install` без интерактива падает на неподтверждённых инструментах.**
Сначала нужно выполнить `rokit trust <автор/инструмент>`.

**`simulate_keyboard_input` с `tap` и `duration` может вернуть ответ раньше, чем клавиша отпущена** (не перепроверено). После ответа персонаж продолжал идти.
