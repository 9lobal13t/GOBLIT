## Фаза 1 — технический фундамент 🔶

**Критерий завершения (ТЗ 34):** игрок может войти, двигаться, видеть интерфейс и взаимодействовать с тестовым объектом.

Сделано:

- запуск сервера и клиента с порядком `init → start` и изоляцией ошибок;
- `ErrorReporter`: централизованная обработка ошибок с подавлением спама;
- сетевой слой: реестр событий, лимиты частоты, проверка аргументов, учёт нарушений без автонаказаний;
- `PlayerDataService`: профиль в DataStore с блокировкой сессии, миграциями, автосохранением, `BindToClose` и безопасным отказом при недоступном хранилище;
- `HeroService`: базовое состояние героя, атрибуты для HUD;
- настройки (масштаб интерфейса, подсказки) с проверкой на сервере и сохранением в профиле;
- Застава из примитивов: площадь, стены с невидимым барьером, башни с жаровнями, арка-ориентир, точка появления, освещение;
- маяк — тестовый интерактивный объект, общий для всех игроков;
- HUD: здоровье, выносливость, уровень, зона, валюты, предупреждение о сохранении; уведомления; панель настроек; приветственная подсказка;
- масштаб интерфейса под экран и настройку; поддержка геймпада в настройках;
- 46 тестов, проверка типов, проверка свойств интерфейса, единый скрипт `tools/check.sh`.

**Проверка в Studio (20.10.2026)** выполнена локальной сессией Claude Code через `robloxstudio-mcp` ([отчёт](reports/phase1-studio-check.md)). Найдены 4 проблемы. Все исправлены в части **1.1**:

1. Ошибка DataStore в Studio не распознавалась, и сохранение отключалось только через ~10 с. Добавлен `Logic/DataStoreErrors` с тестами на настоящих сообщениях.
2. Персонаж мог появиться до постройки Заставы. Добавлен `SpawnService`, автозагрузка персонажей выключена.
3. На iPhone 7 текст был 9 точек, кнопки — 22 точки. Масштаб теперь учитывает способ ввода, кнопки не ниже 44 точек, список настроек прокручивается.
4. Кнопка теряла фон. `AutoButtonColor` отключён, контраст вариантов увеличен.

Дополнительно интерфейс переведён на шрифт Montserrat: кириллица в Builder Sans не подтверждена.

**Независимая проверка исправлений (1.2).** Четыре агента посмотрели код с разных сторон, а пятый пытался опровергнуть их находки. Подтверждены и исправлены 5 из 8:

1. Под `UIScale` прокрутка настроек могла не доставать до последних кнопок. Область прокрутки теперь задаётся кодом.
2. Чат Roblox на ПК закрывал название зоны и валюты. Раскладка HUD обходит его угол.
3. На узких телефонах полоса здоровья заходила на кнопку прыжка. При сенсорном вводе она теперь сужается.
4. Studio с доступом к API писал бы в боевое хранилище. Для Studio сделано отдельное хранилище `_Studio`.
5. Блокировку профиля можно было забрать быстрее, чем закончится финальная запись прошлого сервера. Теперь в блокировке есть идентификатор сессии, захват не раньше 30 с и каждый захват пишется в лог (`Logic/SessionLock`).

Три находки не подтвердились (скрытая проблема API хуков выгрузки записана в ARCHITECTURE; CanvasGroup; эффекты Lighting — вынесено в проверку R13).

**Проверка 1.2 в Studio (20.10.2026).** Из 13 пунктов 9 зелёных, два с замечаниями. Исправлено в части **1.3**:

1. На сенсорном экране настройка «Мелкий» уменьшала кнопки до 37 точек вместо 44. Теперь при сенсорном вводе интерфейс не уменьшается ниже макета.
2. В опубликованном месте остались эффекты освещения из шаблона Roblox и складывались с нашими (два `Atmosphere`, два `Bloom`). `HubService` убирает чужие эффекты при старте.

Открыто: R7 — в длинном описании настроек видны промежутки внутри слов. Причина неизвестна, похоже на подстановку другого шрифта. План диагностики — R16 в [TESTING.md](TESTING.md).

Осталось для статуса ✅: проверка R11, R12, R14–R16 в [TESTING.md](TESTING.md), разбор R7 и пункт 13 (геймпад).

Известные ограничения фазы 1:

- здоровье и выносливость пока не меняются: источников урона и трат ещё нет (фаза 2);
- валюты показываются, но заработать их пока нельзя (фазы 2–3);
- данные перков, врагов и комнат лежат в `Definitions` и проверены тестами, но системами пока не используются (фазы 2–3).

## Фаза 2 — первый играбельный прототип (следующая)

**Критерий завершения:** полностью работает короткая экспедиция из нескольких комнат.

План:

1. **Логика без Roblox API (с тестами):** `Stats` (модификаторы и пределы характеристик), `DamageFormula` (единый расчёт урона с защитой от NaN и отрицательных значений), `Leveling` (кривая опыта), `PerkPool` (выбор предложений по весам редкости и стакам).
2. **Бой на сервере:** запрос атаки передаёт только направление. Сервер сам проверяет кулдаун, дистанцию, сектор и линию видимости и считает урон в `DamageService`.
3. **Враг «Шелуха»:** серверный AI с состояниями Idle / Chase / Telegraph / Recover, атака с заметным телеграфом, полоса здоровья.
4. **Тренировочный манекен на Заставе:** проверка урона без подземелья.
5. **Вход в подземелье:** врата на месте арки. Подземелье пока из фиксированной цепочки комнат; процедурная генерация — фаза 3.
6. **Опыт, уровень и выбор одного из трёх перков:** интерфейс карточек; перки реально меняют характеристики.
7. **Простой выход:** возвращение на Заставу с экраном итогов.

## Риски и как с ними работаем

| Риск | Где | Мера |
|---|---|---|
| Рассинхрон мира между игроками | генерация, мультиплеер | вся генерация на сервере по seed; мир один и реплицируется Roblox, клиент ничего не генерирует |
| Недоступная цель или дверь в пустоту | генерация | граф на сетке с проверкой связности и правил размещения; тесты на тысячах seed в Lune; запасная линейная раскладка |
| Ощущение «удар не прошёл» из-за задержки | бой | клиент сразу показывает взмах, сервер считает попадание; телеграфы врагов дольше типичного пинга; окно неуязвимости при уклонении |
| Читер шлёт «я нанёс 50 000 урона» | бой, награды | клиент отправляет только намерение; урон, награды и опыт считает сервер; лимиты частоты |
| Потеря или дублирование прогресса | сохранение | блокировка сессии, `UpdateAsync`, атомарные изменения, хуки выгрузки; позже — идемпотентная обработка покупок |
| Падение производительности при 6 игроках | AI, эффекты | AI тикает с интервалом, а не каждый кадр; лимиты врагов на зону и комнату; ограниченные пулы эффектов |
| Код нельзя запустить вне Studio | весь проект | чистая логика тестируется в Lune; API Roblox проверяет тип-чекер; ручной план на каждую фазу |

## Временные замены
