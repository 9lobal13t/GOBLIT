# GOBLIT — правила для ИИ-помощника

Claude Code читает этот файл в начале каждой сессии в репозитории. Здесь записаны правила работы — это память проекта между разговорами. Описание устройства кода — в `docs/ARCHITECTURE.md`, план — в `docs/ROADMAP.md`.

## Владелец и общение

- Владелец игры — Артём, начинающий разработчик. Отвечай по-русски, просто и по шагам. Будь честным, а не вежливым: если идея слабая, скажи прямо и предложи лучше.
- Важные решения — только с явного согласия Артёма: публикация игры, всё, что связано с Робуксами, удаление навсегда, действия на сайте Roblox. Пароли, токены и ключи не запрашивай: входит он сам.

## Как работаем

- Работаем по фазам из `docs/ROADMAP.md`. Одна фаза (или её часть: 2а, 2б…) — одна законченная вещь. Не распыляйся на несколько задач сразу.
- Порядок каждого этапа: код → `./tools/check.sh` → план ручной проверки в `docs/TESTING.md` → документы → коммит в `main` → `git push`.
- «Готово» — только после проверки. Что не проверено в Studio, так и пиши: «не проверено вживую».
- Отчёт в конце этапа всегда в одной форме: **что сделано / как проверено / что НЕ проверено / что сделать Артёму / следующий шаг**.
- Каждую найденную ловушку (Roblox, Luau, инструменты, среда) записывай в `docs/PITFALLS.md`, чтобы не наступать на неё снова.
- Документы описывают только то, что реально сделано. Планы помечаются статусом.

## Правила кода

- **Клиент просит — сервер решает.** Клиент присылает намерение, а сервер сам проверяет право, расстояние, частоту и состояние и считает результат. Урон, награды, валюту и сохранение клиент не определяет никогда.
- Числа баланса — в `src/shared/Config.luau`, содержимое (перки, враги, комнаты) — в `src/shared/Definitions`, имена атрибутов и тегов — в `Constants.luau`. Никаких «магических» строк и чисел по коду.
- Чистая логика — в `src/shared/Logic`: без Roblox API и без `require`, зависимости передаются параметрами. На каждый такой модуль пишутся тесты Lune в `tests/`.
- Сетевые события объявляются только в `src/shared/Net/Remotes.luau`, с форматом аргументов и лимитом частоты. Каждый аргумент проверяется на сервере (`Guard`).
- Модули стартуют в два шага: подписки на сигналы — в `init()`, работа — в `start()`.
- Профиль меняется только через `PlayerDataService.update`. Изменение схемы требует новой версии, миграции и теста.
- Никаких пустых файлов-заготовок «на будущее».
- Русский текст в интерфейсе пишется шрифтом с кириллицей и только символами, которые в этом шрифте есть (см. `docs/PITFALLS.md`).
- Интерфейс проверяется расчётом на маленьких экранах (iPhone 7, бюджетный Android) уже с первых окон.

## Среда

- Studio подключается к **локальной** сессии Claude Code через плагин `robloxstudio-mcp` (см. `docs/LOCAL_SETUP.md`). Studio используется только для проверки: запуск игры, Output, скриншоты. Скрипты правятся в файлах и попадают в Studio через Rojo. Инструменты, меняющие скрипты в Studio, запрещены в `.claude/settings.json`.
- Облачная сессия Studio не видит. Roblox Studio и Blender там недоступны. Автоматические проверки запускаются командой `./tools/check.sh`. Поведение в Studio проверяет Артём по плану из `docs/TESTING.md` или локальная сессия, подключённая к Studio.
- Опыт прошлого проекта Артёма — в `docs/LESSONS_BRAINROT_BANDITS.md`. Используй его как чек-лист, но каждое правило проверяй на этом проекте.
